# S3K CRM

Monorepo for the S3K CRM application.

## Structure

```
├── frontend/   Next.js UI (port 3000)
└── backend/    Express API (port 4000)
```

## Quick start

Install dependencies from the repo root:

```bash
npm install
```

Run the frontend:

```bash
cd frontend
npm run dev
```

Or from the root:

```bash
npm run dev:frontend
```

Run the backend:

```bash
cd backend
npm run dev
```

Or from the root:

```bash
npm run dev:backend
```
